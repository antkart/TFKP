```bash
julia install.jl
```

## Запуск

```bash
julia main.jl
```

Скрипт создаст файл `conformal_mapping_steps.png` с визуализацией всех этапов отображения.

## Что делает скрипт

1. Генерирует сетку точек для исходной области D₁ (ℂ \ [0, i])
2. Выполняет конформное отображение через несколько этапов:
   - Поворот на -90° (z₁ = -i·z)
   - Отображение в верхнюю полуплоскость (z₂ = √(z₁/(1-z₁)))
   - Отображение в верхний полукруг (w = (z₂-i)/(z₂+i))
3. Создаёт визуализацию всех этапов
4. Сохраняет результат в PNG файл
